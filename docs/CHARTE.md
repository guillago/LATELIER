# L'atelier — charte graphique

**Concept :** Art & Gourmandise · **Message :** Le plaisir d'offrir — petits cadeaux et créations faits main par Inès, 13 ans, passionnée de dessin, accompagnés des gourmandises de sa sœur Salomé.

## Couleurs (tirées des aquarelles d'Inès)

| Rôle | Nom | Hex |
|---|---|---|
| Fond | Papier crème | `#FBF6EE` |
| Texte, logo | Encre prune | `#462C3A` |
| Art | Bleu lagon / pastel | `#4F86C6` / `#BFD9F2` |
| Gourmandise | Rose framboise / pastel | `#E0607E` / `#F6C3CF` |

## Typographies (Google Fonts, gratuites)

- **Fraunces** — titres, logo
- **Caveat** — mots manuscrits, signature, accents
- **Nunito** — texte courant

## Logo

Logo créé avec Claude Design : une cuillère (gourmandise) croisée avec un pinceau (art), sur une tache d'aquarelle bleu pastel.
Fichiers dans `img/logo/` :

| Fichier | Usage |
|---|---|
| `logo-couleur.webp/.png` | Version principale, sur fond clair |
| `logo-clair.webp/.png` | Sur fond foncé (encre prune, photo) |
| `logo-mono.webp/.png` | Une couleur (tampon, étiquette, impression N&B) |
| `logo-icone-512.png` | Icône seule (réseaux sociaux, étiquettes) |
| `../favicon.png`, `../apple-touch-icon.png` | Onglet du navigateur, raccourci mobile |

Aperçu de l'affiche A3 : `docs/affiche-A3-apercu.webp`.

## Ton

Doux, lumineux, artisanal. On tutoie l'émotion (« le plaisir d'offrir »), jamais enfantin.
